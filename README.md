Travlr Getaways – Full Stack Web Application
Architecture

This project includes two frontends: an Express site using Handlebars for the customer view and an Angular single-page application for administrators. The backend uses a NoSQL MongoDB database for flexible trip storage and efficient updates.

Functionality

JSON was used to connect both frontends to the backend through RESTful API calls. I refactored components, routes, and services to improve efficiency, especially within Angular, where reusable components helped reduce repeated code.

Testing

I tested API endpoints using Postman and the Angular interface. After adding JWT authentication, testing required valid tokens for protected routes, giving me experience with secure API communication.

Reflection

This course strengthened my skills in full stack development, including API design, MongoDB, Angular, Express, routing, and authentication. Completing the full application improved my confidence and prepared me for future development roles.
